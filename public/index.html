Developer API — free, no key, CORS enabled

One endpoint. Returns JSON. Use it in scripts, CI, bots, anywhere:

curl "…/api/expand?url=https://bit.ly/abc123"

Response:

{
  "ok": true,
  "finalUrl": "https://the-real-site.com/page",
  "finalHost": "the-real-site.com",
  "https": true,
  "redirects": 2,
  "chain": [ { "url", "status", "ms", "type", "next" }, … ]
}

Optional: &max=30 to raise the hop limit (default 15). Health check at /api/health.

Quick one-liner to get just the final URL:

curl -s "…/api/expand?url=$LINK" | jq -r .finalUrl
